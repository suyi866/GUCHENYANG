记账本 PWA 版 - 使用说明
========================

这是可安装的网页应用（PWA），包含：
  index.html            主程序（浏览器打开）
  manifest.webmanifest  应用清单
  sw.js                 离线缓存服务
  icons/                应用图标（4 个）

--------------------------------------------------
一、电脑上使用
--------------------------------------------------
直接双击 index.html 即可记账（功能与单文件版一致）。

--------------------------------------------------
二、手机上使用（两种方式）
--------------------------------------------------
方式 A：电脑开临时服务器，手机连同一 WiFi 访问
  1. 本文件夹下打开命令行，运行：
       python -m http.server 8000
  2. 查看电脑局域网 IP（命令行输入 ipconfig，找 IPv4 地址）
  3. 手机浏览器访问： http://电脑IP:8000
  4. 打开后，在浏览器菜单选“添加到主屏幕”。

方式 B：部署到免费静态托管（推荐长期使用）
  任选其一，把本文件夹里的全部文件上传：
  - GitHub Pages：新建仓库 -> 上传文件 -> Settings -> Pages 开启
  - Gitee Pages ：新建仓库 -> 上传文件 -> 服务 -> Gitee Pages 开启
  - Netlify Drop：打开 app.netlify.com/drop，把整个文件夹拖进去
  部署后会得到一个 https 网址，手机、电脑都能访问并可安装。

--------------------------------------------------
三、添加到主屏幕（装成“App”）
--------------------------------------------------
  Android Chrome：菜单 -> 添加到主屏幕 / 安装应用
  iPhone Safari ：分享按钮 -> 添加到主屏幕

--------------------------------------------------
四、数据说明（重要）
--------------------------------------------------
  - 数据保存在浏览器本地存储（localStorage），按设备独立，
    手机和电脑的数据不会自动同步。
  - 请定期点页面右上角“导出 JSON”备份；换设备用“导入”恢复。
  - 清除浏览器缓存/数据会导致记录丢失，务必先导出备份。

--------------------------------------------------
五、常见问题
--------------------------------------------------
  - 双击打开为什么不能“安装”？
    PWA 需在 https 或 localhost 环境下才能触发“添加到主屏幕”，
    file:// 打开只能当普通网页用（记账功能不受影响）。
  - 离线能用吗？
    部署或本地服务器访问过一次后，再打开可离线使用（数据在本机）。
